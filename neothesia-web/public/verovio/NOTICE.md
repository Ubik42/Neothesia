# Verovio

The application includes unmodified Verovio 6.1.0 ESM and WebAssembly modules,
licensed under LGPL-3.0-or-later. These modules are separate from the application
bundle and are loaded only by the notation worker.

Upstream source: https://github.com/rism-digital/verovio/tree/version-6.1.0
License: https://github.com/rism-digital/verovio/blob/version-6.1.0/COPYING
Module version: 6.1.0 (the same pinned package used by the local renderer audit).
