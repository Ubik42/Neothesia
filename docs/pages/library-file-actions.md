# 曲库文件操作

在曲库管理的曲目行右键，或聚焦行后按 Shift+F10/菜单键。右键已选行保留多选；右键未选行只选择该曲目。打开练习、编辑信息和学习目标作用于右键行；收藏、队列、检查、复制作用于所选文件，加入分组会转到下方目标分组控件。系统文件位置作用于右键行，只在桌面版启用。文件缺失时打开可用的上级文件夹。

Ctrl+F 搜索，表格 Ctrl+A 选择全部筛选结果，Ctrl+C 复制所选文件位置，每行一个。F2 编辑当前行；Enter 打开，方向键/翻页移动，Shift 连选，空格切换选择。输入框中的全选/复制仍编辑文本。菜单方向键及 Home/End 选择可用项，Esc 关闭后回到原行。

收藏与队列每批最多 100 个文件，同内容副本去重，不切换当前练习。每项重新核对实际内容，文件被替换时拒绝旧操作。途中停止等待当前项结束，保留已完成项；失败逐项列出，其他项继续。收藏/队列视图会同步更新。生成练习的虚拟文件行不提供物理文件操作。

信息编辑增加取消入口，保存或取消之前不切换曲目或关闭曲库，避免草稿被清空。文件位置和复制只定位、复制路径，不移动或删除文件。

信息编辑读取文件的真实内容与已有字段，保存会再核对。另一处修改过资料时会显示逐字段对照：不同字段默认保留各自修改，同字段双方改动必须选择采用哪份。合并只更新草稿，核对后再保存；期间再次改动仍会阻止覆盖。可读取最新资料审阅，或明确放弃草稿采用最新。文件被换成另一首、资料不可读或损坏时不写入；草稿可复制出来，再取消并检查文件。指法、分手和谱面关联继续保留。

## 批量修改资料与资料模板

在曲库中多选曲目，点底部“批量修改资料”。每批最多 100 个实际文件；相同演奏的副本也各自读取和修改个人资料。选择每个字段的操作，曲名继续保留。标签可添加、移除指定项或替换全部，备注可追加或替换。空白内容不能冒充清空，需明确选择“清空”。

点“读取修改预览”，展开每行查看原资料和修改后内容。勾选要保存的文件，再点“保存所选修改”。保存会核对预览后有没有改过资料、文件是否仍为同一首；冲突和错误逐项显示，其他文件继续处理。可停止批次，已完成项保留。冲突需重新读取、查看最新变化后再保存。没有变化的字段或文件不会重复写入；同一段备注已经在末尾时不重复追加。

填写模板名称并“保存模板”，以后选择模板再读取曲目预览。更新已有模板、移除或刷新列表不会直接修改曲目；其他位置改过模板列表时会拒绝旧版本覆盖，当前字段设置保留。最多 50 套，重启保留。模板保存在应用数据内，也可通过练习资料备份的“片段、阶梯、技术练习、音轨与资料模板”范围迁移；导入可预览字段与规则，同名冲突按所选策略处理。

## 资料变更历史与恢复

选择曲目后，在详情打开“资料变更历史”。功能启用后的单首编辑、批量修改和恢复会记录修改前后内容，每个文件保留最近 200 次写入。选择一条记录查看字段差异，再点“预览恢复到修改前”。

恢复只处理该次改变的字段。没有后来修改的字段默认恢复，后来又改过的字段须明确选择保留最新或恢复目标值。保存恢复前再次核对资料基线，预览后再改动会返回冲突，需要重新读取审阅。恢复本身也生成一条记录，选择它可反向恢复。原指法、分手和谱面关联保留。

文件缺失、换内容或附加资料无法读取时仍可查看已记录历史，不能直接恢复。写入失败或未确认的历史项可阅读，不用来直接恢复。历史目前保存在应用数据，按文件位置和内容身份区分，不随练习备份携带；导入与外部程序改动不会追溯补记。
