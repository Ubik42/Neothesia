# 在曲库管理谱面版本

打开“曲库管理”，选择一首已索引的本地曲目。右侧的“谱面资料”列出全部演奏乐谱和 PDF/图片，包括未关联的版本。没有索引时先检查文件。

查看资料和改名不切换当前练习曲目。演奏乐谱可改名、解除关联、设置为关联谱面及移除未关联的登记；设置关联时先核验实际 MIDI 和谱面。关联是这首曲目的默认打开乐谱，当前曲目相同时会切换并暂停参考演奏。移除登记先确认，文件仍保留。

PDF/图片可改名、选择常用、移除登记或独立预览。预览不改变常用谱页，翻页/缩放/旋转会保存阅读状态。Escape 先关闭预览，曲库继续显示；侧栏更新保存的页码。MIDI 缺失时仍可管理资料、预览完整谱页，打开练习前需要重新定位 MIDI。

“打开乐谱练习”和“打开谱页练习”才切换到该曲目和指定版本。失效谱面不能作为指定版本打开；同一 MIDI 路径换成其他内容时先重新检查，避免把旧谱关联到新曲目。

文件核对区分可用、内容改变、缺失和无法读取。“重新检查谱面资料”重新读取实际文件并核对哈希。容量按 B、KB 或 MB 显示，展开“文件位置”可查看路径。

相同名称、相同内容的 MusicXML/MXL 重复导入会复用版本和编号；可修复应用副本，外部原文件不重写。不同名称保留为不同版本。旧的同名同内容重复登记显示份数，可选择保留一份并合并；全部物理文件保留，相关关联迁移到保留版本。

当前曲库侧栏负责查看、整理和预览。添加新文件或重新导入修复仍在主练习区的“谱面管理”完成；曲库内批量添加与集中修复继续开发。

## 曲库内添加与修复

选中已索引曲目，在“谱面资料”添加演奏乐谱或 PDF/图片，可多选。演奏乐谱登记后再选择是否关联；同批图片合并为一份多页谱，PDF 单独登记。已有图片谱可追加图片、调整页序或确认移除页登记，文件副本仍保留。

文件缺失或内容变化时，选择“用原文件修复”或“修复此页原文件”。只有与原登记内容一致的文件才用于修复，版本名称、阅读位置和常用设置保留；不同版本请使用添加入口。无法恢复的外部乐谱会建立应用副本，原文件不会重写。

一次最多 100 份文件，逐份显示结果，某份失败后继续。可在当前文件处理后停止，已成功的内容保留。跨多首曲目逐文件配对仍是开放功能。


## 多首曲目批量配对

在“导入曲目”中选择“批量配对谱面”，一批加入 MIDI、MusicXML/MXL、PDF 和图片。点击“导入 MIDI 并读取配对候选”，先把本批 MIDI 保存到曲库，再核对谱面归属；只有谱面时点击“读取曲库配对候选”。

同名仅提供候选，不判断演奏、编订和纸谱版本一致。多份同名演奏需要“选择曲目”，可按曲名、作曲家或实际文件路径搜索。每份谱面可“预览”实际内容，PDF 和演奏乐谱可以翻页检查。

勾选要保存的配对。同一首曲目下，图片纸谱名称相同的图片按列表顺序组页，可上移/下移；使用不同名称建立不同图片纸谱。PDF 和 MusicXML 各保存为独立版本。取消勾选的谱面不会保存。

“保存选中配对”逐文件处理，一份失败不会阻止后续文件。已完成项不会重复保存；暂停会处理完当前文件，再次保存继续剩余选中项。先保存了较后的图片页，后来补前页时需要下移到已保存页之后，或使用另一份纸谱名称；已存纸谱也可在曲库谱面管理中重新排页。

关闭窗口保留已完成结果；点击“保存此批次”后，尚未处理的文件副本和配对队列也可继续。未保存为批次的文件队列只在当前窗口内保留。本次配对采用缓存副本，不自动建立原件路径监视；原件长期关联仍使用曲库谱面的原件关联入口。


## 保存和继续整理批次

填写批次名称，点击“保存此批次”，保存实际文件副本和整理进度。保存后，勾选、人工配对、图片分组和顺序修改会自动更新；导入、配对每个文件前后记录进度。关闭时等待最新存档完成。一个批次最多 200 项、512 MB；空间不足会显示失败，不会显示为保存成功。

点击“已保存批次”，查看时间、完成数、容量和待核对项，选择“继续此批次”。重开后完成项不再保存；未完成图片继续追加到此前创建的同组纸谱。多窗口修改同一批次时，较旧的窗口会被拒绝，需要重新打开保存版本。

软件在保存途中退出时，谱面进入“上次保存中断，请核对已保存结果”。点击“核对中断项”，引擎按真实演奏和目标纸谱检查文件的实际字节。已有同内容谱面时选择“采用此保存结果”；没有登记文件时选择“恢复为待保存项”，再继续保存。采用前仍会重新核对；演奏或谱面变化后不会直接采用旧检查结果。

移除批次会删除其整理副本和进度，已经导入的曲目、演奏乐谱、纸谱及原文件保留。确认窗口会显示名称和文件数量。

保存批次位于当前应用或浏览器的本机资料存储中，桌面版和 Web 版分别管理；清除应用/浏览器资料会移除它们。目前批次不随曲目包或练习备份导出，不支持跨设备搬迁。已有曲目和谱面的打包、备份沿用原入口。
