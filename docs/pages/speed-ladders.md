# 速度阶梯

在等音或连续模式下，从练习参数右侧的“速度阶梯方案”进入。每首曲目最多保存 200 个命名方案；每个方案保存自己的小节范围和晋级规则，以及声部、左右手、预备、节拍器和输入校准设置。

起始和目标速度为参考 MIDI 的百分比，范围 25%～200%；每次增加 1～50 个百分点，最后一级会准确停在目标速度。例如 50%、步长 10、目标 65% 得到 50 → 60 → 65。

每一级必须连续达到指定轮数（1～10）才晋级。正确率至少 50%～100%，错音和漏音均计入分母；只有完整覆盖该选段目标音符的结果才可晋级。连续模式还可要求正确音符中的准时率；等音不评价节奏，不允许此门槛。

未达标会清除连续达标次数，可重复当前速度，或在连续若干轮未达标后回退一级，起始级不会再降低。每次练习可限定最多 1～500 轮；到达上限停止，进度保留，再选择继续即可开启新一批轮数。

保存并应用后，需要按主界面“开始练习”。方案在目标速度也达标后停止。主界面显示当前级别、速度、连续达标进度、标准、总轮数与最近结果。普通自适应提速在阶梯内关闭。

暂停保留当前轮；结束阶梯保留已获得的级别和进度。重新启动软件后不会自动演奏或自动启用阶梯，从方案窗口选择“继续保存进度”即可从保存级别开始完整的新一轮。“从起始速度应用”重新练习整个阶梯。

每个方案独立保存进度。仅改名保留进度；改变范围、声部、晋级规则等条件会清除原进度。网格或逐音分手改变时，旧方案拒绝应用，需要核对范围并重新保存。阶梯期间保护速度、声部、导航等条件；提前保存、录音和普通循环设置需先结束阶梯。

历史保存当轮方案和级别；低于方案目标速度的结果不会作为复习掌握证据。等音阶梯可帮助准确率练习，不能替代连续模式的节奏达标。

阶梯方案随曲目包携带、每日计划和更完整的阶段目标仍在开发。
