# 显示与电脑键盘

在练习区工具栏打开“显示设置”。可选择音名、固定唱名、大调级数，以及音符显示名称、指法、组合或隐藏。固定唱名以 C 为 Do；级数以所选主音为 1，右下数字表示绝对音区。它们只改变文字提示，不移调演奏；级数当前使用大调排列，不推断小调调式。

键盘标签支持仅 C、全部白键、全部键或隐藏；可调整字号，左右手可改为蓝橙配色，未分手显示灰色。窄键文字会缩小，放不下时隐藏。指法优先使用已有标记，未标记显示名称；仅指法模式不会临时生成建议。背谱模式仍隐藏目标音符提示。

电脑键盘可选择 C2–C3 至 C6–C7 的起始音区，使用 A S D 行或 Z X C 行，点击对应音后按新键逐音修改。每个键只分配给一个音，可使用字母、数字和逗号/句号/分号。按物理键位识别，支持和弦；组合快捷键、输入框和对话框内不演奏。Esc 取消捕获，再按 Esc 关闭设置。切换映射、打开设置或窗口失焦会释放此前按住的音。

显示偏好、电脑键盘布局、键盘范围、预览小节数及曲库/练习参数面板开关即时保存在此应用的本机页面存储，重启仍保留。浏览器开发版和打包桌面版使用各自的页面存储；这些偏好暂未包含在曲目包或练习资料备份中。

## 练习室布局与尺寸

打开“显示设置”，在“练习室布局”中调整曲库宽度、练习参数宽度、琴键高度及纸谱上方键盘区域。立即生效并保存在本机；窄窗口按可用空间限制侧栏尺寸。曲库与参数面板边缘还可以直接拖动；聚焦边缘后，方向键每次调整 10 像素，Shift 每次 40 像素，Home/End 到最小/最大尺寸。

“读谱”隐藏曲库、保留参数并缩小琴键区域；“选曲”扩大曲库并隐藏参数；“专注练习”隐藏两侧面板并增大琴键。可继续调整后输入名称“另存当前布局”。

已保存方案可选择并“应用布局”。“更新当前布局”保存当前尺寸、面板开关和名称；“仅改名”保留原方案尺寸，只修改名称；“删除布局”移除方案，当前显示不变。最多保存 24 个方案，名称 1～40 个字，不允许重名。

方案只保存布局字段，不覆盖电脑键盘映射、音名、曲目练习条件或成绩。方案保存在本机，可通过独立界面设置备份迁移；尚未合入练习资料备份。

## 操作快捷键

“显示设置 → 操作快捷键”列出当前绑定。点击某项按键，再按新的组合；Esc 取消录入。可以清除某项，或恢复全部操作快捷键默认值。自动保存在本机，电脑键盘弹奏的音符映射单独设置。

默认空格播放/暂停，Ctrl+Home 从头开始，Alt+左右方向键移到相邻小节，Ctrl+减号/等号减速/加速 5%，Ctrl+M 开关节拍器，Alt+C 开关当前分段循环。Alt+V 切换键盘/乐谱/纸谱，Alt+B/I 切换曲库/参数侧栏，Ctrl+逗号打开显示设置，Alt+H/P/L 分别打开历史/练习段落/曲库管理。暂停并停止发声可自行分配。

组合不能与另一个操作重复，裸按键不能与电脑键盘弹奏重复；保留给系统/浏览器的部分组合不可使用。输入文本和打开窗口时，全局练习操作暂停。完整演奏和背谱中，定位、变速与循环沿用专用控制限制；节拍器仍可切换。计划和阶梯中的条件使用对应控制。

默认值和自定义绑定都按键盘物理位置识别。底栏和播放按钮提示当前绑定。任意编辑器命令仍未接入；操作快捷键可通过独立界面设置备份迁移。

## 界面设置备份与恢复

“显示设置 → 界面设置备份 → 导出界面设置”保存 .neosettings 文件，包含当前显示/面板、电脑键盘弹奏、操作快捷键和命名布局。桌面版选择保存位置，浏览器版下载文件。它用于迁移界面习惯，曲目、指法、计划和成绩仍使用练习资料备份。

点击“读取界面设置备份”，选择文件后先预览。显示与面板、电脑键盘弹奏、操作快捷键可以分别勾选，展开差异表查看本机与备份值。各命名布局可以加入、跳过；同名方案默认保留本机，也可选择使用备份方案。

点击“恢复所选设置”才应用。恢复结果出现操作快捷键与弹奏键冲突时，需要同时恢复两组或保留其中一组，再核对；设置或布局在审阅期间变化时，点击“重新核对本机设置”后再审阅。最多保留 24 个命名布局，坏格式、未知版本、无效范围/绑定和超过 1 MB 文件拒绝恢复。

恢复写入失败会尝试回退原设置，若回退也失败会明确提示重新核对本机资料。导出后保留文件可用于重开或另一台机器恢复。界面备份目前为独立文件，尚未合并进入练习资料备份。

## 整体缩放与窗口适配

“显示设置 → 练习室布局 → 整体缩放”调整 80%～150% 的整体界面大小，工具栏、面板与窗口一起变化；琴键标签和鼠标/触屏按键按同一缩放计算。“恢复 100% 缩放”回到默认大小，“适应当前窗口”按屏幕空间选择 80%～100% 的比例。

默认 Alt+Shift+等号放大 10%，Alt+Shift+减号缩小 10%，Alt+Shift+0 恢复 100%；可在操作快捷键中修改。这些查看操作可在普通设置窗口内使用，录入快捷键时会作为录入内容处理。

缩放在本机自动保存，也随命名布局及界面设置备份携带。旧备份补 100% 默认大小；新增缩放组合若被旧操作占用，会保留旧绑定。较窄窗口中菜单栏可横向滚动或通过键盘焦点访问末尾操作。
