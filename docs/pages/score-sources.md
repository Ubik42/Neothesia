# 原谱文件与保存版本

桌面单文件打开 MusicXML/MXL、曲库添加演奏乐谱会保留原文件位置和导入内容身份。旧数据或浏览器导入没有原路径，可在谱面版本旁“关联原谱文件”，选择与该版本内容一致的原件。仅凭文件名不能认定来源。

曲库“原谱文件”查看全部关联；谱面管理“检查原谱更新”查看当前曲目。支持搜索、状态筛选和分页。登记原件随文件夹监控每 5 秒检查，只有时间/大小改变时读取校验；窗口内和立即检查直接核对内容，应用始终再读取。全库自动更新开关控制后台检查，不自动覆盖谱面或开始演奏。

原件改变后先预览：实际演奏音符/时长、缺省速度、是否仍为同一演奏身份、与旧 MIDI 的对应率和导航提示。可以添加为新谱面版本，原曲/原版本保持，另选新版本使用；或重新生成并打开演奏。相同 MIDI 内容身份继续原资料，内容不同建立另一曲目，旧逐音指法、分手、成绩、片段与计划不自动迁移。手动关联从旧 MIDI 起始速度推断缺省值，谱内速度标记继续优先。

演奏、录音、计划和阶梯中不能应用；窗口可以停止当前练习，录音先通过录制窗口结束。预览后原件或关联变了会拒绝旧请求。保留当前版本后，再次修改原件仍会提示。取消关联只移除原件追踪，不删除谱面、曲目或成绩。

保存版本使用独立副本，原件丢失仍可阅读/练习。旧外部关联先迁入本机；选择保存文件自身作原件，也另建保护快照。修改期间版本已经保存、但原件再次变化导致关联/确认失败时，明确报告并保留已保存版本供核对。

原路径存于本机原谱关联资料，不随曲目包或练习备份导出。其他电脑可以使用包内谱面，需重新关联其本机原件。PDF/图片原件追踪、批量原谱更新和跨演奏身份资料迁移仍待开发。

复杂导航等暂不能生成演奏时，预览明确原因并禁用演奏创建，仍可保存为新谱面版本供阅读/后续核对；不会把不支持的跳转按顺序演奏。


## 批量检查与更新

在原谱窗口按曲名、版本名或文件位置筛选，勾选要检查的更新；选择可跨页保留，每批最多 100 个版本。打开“批量预览”后生成逐项预览，查看内容身份、对应率和警告。处理方式默认跳过，逐项选择添加新谱面、保留当前版本或生成演奏，再执行所选处理。

添加谱面或保留版本继续当前演奏；生成演奏会依次打开，最后停留在最后成功生成的曲目。不能生成的谱面仍能选择添加新版本。每项执行前再次核对原文件，失败项显示原因并继续其他项；停止批次会等待当前项完成并保留完成结果。失败或未预览的项可返回列表重新检查，完成项不会在同一批次中重复执行。
