# 曲目学习

在曲库管理中选择一首已索引曲目，打开“学习目标”。可以选择学习阶段，设置目标日期、每周计划时长、目标速度和自己的达标要求。阶段由你确认；这些数值是计划，不代表软件已经判定你达标。曲库可按学习阶段、逾期或今天到期筛选，按阶段/目标日期排序。

学习资料按曲目实际内容保存，相同内容的文件副本共用。文件位置变化或已知原件缺失不丢失目标；同路径替换成另一首不会继承目标。批量设置阶段只处理已索引曲目，相同内容去重，每批最多 100 首，并保留目标日期、速度、时长和文字要求。出错项显示原因，其他项继续。

阶段变更记录保留最近 64 次。未保存修改关闭时可以继续编辑或放弃；他处修改后拒绝旧编辑覆盖，请重新打开核对。移除学习目标只取消这首曲目的学习资料，曲目、谱面和成绩仍保留。

练习备份中的“计划、日课与曲目学习”包含这些资料；新资料使用 v3，导入前会显示学习资料冲突，按保留本机或使用备份处理。曲目文件仍需另外迁移或在本机索引，备份不会自动复制原 MIDI 或文件位置。

曲库详情和学习目标窗口显示已保存练习用时，可刷新本周与合计。每周计划有用时进度；统计每首最近 200 次已保存结果，按本机周一至周日和保存日期归属。用时按真实运行计，含等音等待，不含暂停、预备拍、聆听和指法示范；未保存或重置的练习不计，旧记录未计时也不按曲长估算。它不是持续实弹时长或终身账本，不自动修改学习阶段。历史列表/详情显示单次用时，成绩备份携带计时。终身累计、跨日分配和自动达标阶段联动继续开发。
