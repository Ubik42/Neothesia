# PDF 与图片谱面

在“谱面管理 → PDF / 图片谱面”添加 PDF、PNG、JPEG 或 WebP。文件副本保存在软件数据目录，并绑定 MIDI 内容身份；原文件移动不影响已保存副本。该功能不会从扫描谱生成演奏。

一份 PDF 是一个版本；一次添加多张图片会按导入顺序组成一份图片谱面，PDF 独立添加。选中图片版本可“追加图片谱页”，查看某页后可前移、后移或移除；最后一页用“移除登记”移除整个版本。移除登记保留副本和原件，目前不清理缓存。

版本下拉框切换、输入名称后保存。主练习区点击“谱页”，即可边练习边查看；可手动翻页，也可在“小节与谱页对应”登记演奏小节后启用自动翻页。软件不从扫描图像自动识别小节。使用上一页/下一页、页码、适合宽度、缩放和旋转控制。谱页区域有焦点时左右键和 PageUp / PageDown 翻页。每份版本保存自己的阅读状态，曲目移动或重开后继续读取。

PDF 密码在当前阅读器输入，仅用于本次打开，不保存密码。文件无法解析或副本缺失时显示错误。重新导入相同单页文件会重新核对内容并修复副本。

单文件最多 48 MB，每曲最多 40 份版本、登记总量 240 MB，每份图片最多 80 页。支持最多 5000 页 PDF；大图需要在 6400 万像素以内。PDF/图片附件可随曲目包携带完整副本、名称、页序和阅读设置；导入可合并保留本地阅读位置或使用包内设置。完整个人数据备份仍待开发。

PDF 渲染使用 [PDF.js 官方逐页与画布接口](https://mozilla.github.io/pdf.js/examples/)，渲染器及字体/解码资源随桌面程序打包，离线可用。


“导出本页批注”另存完整当前页的 PNG，保留旋转及编号位置，页后列出全部已保存文字。PDF 独立重新渲染，不受阅读缩放影响；图片保留原像素或按上限缩小。隐藏批注仍导出已保存内容，未保存草稿不能导出。生成与保存期间锁定本页编辑/翻页，自动跟随暂停；保存成功、取消或失败都保留原资料。每次一页，可外部分享或打印；整本 PDF 排版仍未实现。超大合成明确报错，可用曲目包完整迁移。


## 原件更新与全库检查

在每份谱面“原件位置与更新”中关联对应 PDF 或每张图片的原文件。原文件必须与已保存谱页内容一致；搬家后可以重新关联相同内容的位置。关联不删除或移动文件，解除后保留副本及其资料。

“曲库管理 → 纸谱原件”集中显示所有已关联原件。默认只显示更新、缺失和无法读取，可切换全部关联/忽略/一致，按谱面名称、页名或位置搜索，每页 50 条。曲库“自动更新”开关控制后台检查，暂停后仍可点击“重新检查原件”。程序重开后会重建检查结果。

查看一处关联后，可填写相同内容的新位置或选择原件；更新内容先打开真正的谱页预览，再明确保存新版本或忽略这次更新。原版本批注和小节对应保留；新版本可在谱面管理中审阅资料迁移。忽略按当前内容记录，原件再次变化会重新提示。列出状态到实际保存之间资料或原件变化，会要求重新核对。

后台检查复用没有变化的文件校验，检查不自动采用更新，也不遍历整块磁盘猜测搬家位置。谱页目录损坏会单独提示，其他目录继续检查；缺失原件不影响已保存副本的阅读与练习。


## 高亮、页内小节位置与练习段

“添加高亮区域”后在纸谱上拖出矩形，可只保存高亮，也可写教学说明并改颜色；重新定位再次拖选。旋转、缩放、重开和曲目包迁移均保留原页位置。导出本页批注时绘入区域和编号，页后列出说明。

展开“小节与谱页对应”，填写演奏小节，点击“框选小节位置”后在纸谱拖出这个小节或谱行的范围，再“保存此页对应”。每个对应可只记页码或包含页内位置。开启自动翻页后，软件按实际演奏小节滚动到位置；反复演奏需要分别登记展开后的演奏小节。点页内小节编号或“定位练习”切到对应音乐位置；修改对应使用“查看 / 修改对应”。

每条对应的“建立练习段”可指定前后小节、慢练速度、重复遍数、名称和要求。沿用当前模式、声部/手别、预备拍、节拍器、延迟、自动调速及已保存指法；保存本身不改变演奏位置。保存后“打开练习段”设置实际循环，也可从“练习段落”重新打开、修改或加入练习计划。输入草稿保留在本机；谱页对应或练习条件变化后要“重新核对条件”。完整演奏和背谱模式须先结束后再建立段落。

区域坐标依附具体谱页内容；拍号/小节网格变化时旧对应停用，请审阅后重新确认。不同谱面版本迁移小节对应时可以保留区域或明确“仅迁移页码”，采用前应核对新页位置。


## 手写标记与笔迹核对

“手写标记”进入画笔模式，可改颜色和粗细，在谱页写指法、圈注或连线。“橡皮”点击或划过整笔擦除。“撤销笔画 / 重做笔画”处理本次编辑；“保存笔迹”一次保存本页更改。手写期间自动翻页暂停，先保存或暂存退出后再继续阅读。

“暂存并退出手写”把草稿留在本机，继续手写或重开后恢复；“放弃笔迹修改”明确丢弃草稿。保存后“撤销上次笔迹保存 / 重做笔迹保存”可以恢复本页保存前后笔迹，但本页已被其他编辑改动时会拒绝旧撤销。文字批注、高亮和其他页保持独立。

保存遇到后来编辑时，“核对已保存笔迹”读取当前版本。不冲突的新增、修改和擦除合并；同一笔的冲突分别显示已保存与本机形状、说明或擦除，逐笔选择，默认保留已保存版本。点击“合并到草稿”，查看谱面后再保存；再次有变化仍需核对。

本页批注列表可为手写笔迹添加说明、修改颜色、重新定位区域；相对笔画形状随区域移动/调整。导出本页批注的 PNG 绘入笔迹，写有说明的笔迹列入文字清单。曲目包与谱面版本迁移保留形状和粗细；位置需在目标页核对。

当前橡皮按整笔处理，绘制使用固定粗细；局部擦除、压感和直接对象拖动仍待扩展。每份谱面最多 2000 条批注、20 万笔迹点，每笔最多 4096 点；达到当前笔点数上限时会提示抬起后继续书写。
