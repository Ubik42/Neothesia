# 文件位置

从“曲库管理”打开“文件位置”。同一曲目用 MIDI 内容身份匹配，名称和文件夹不作为相同内容的证明。

“缺失文件”列出文件已不在原位置或原位置换成另一首的记录。先选已核对的可用位置，再重新关联；可以选择本页可匹配项后批量处理。桌面也可以用“选择文件关联”选择外部 MIDI。关联时重新读实际内容，各项独立报告。不会切换正在练习的曲目。

“重复路径”列出多个实际可用副本。设置常用位置决定从收藏、历史或计划重新打开时的优先文件。合并显示保留实际文件，只隐藏源位置的重复行；“恢复路径显示”可恢复。使用默认位置撤销自定义优先项。

“待核对”位置可检查本页或单项核对内容。文件最近改写后，在核对完成前不会当作安全关联目标。

主动替换或移除的旧位置可忽略，再到“已处理”恢复显示。原练习历史保留；同一路径的另一首新曲不会被旧身份的忽略状态隐藏。

关联保留分组、较高评级，恢复原文件的指法等附加信息；目标已有有效附加信息和非空元数据优先。无法写入或冲突会显示警告，需要另行处理。操作不删除 MIDI。

## 文件选择窗口的位置记忆

曲库管理左侧“最近文件位置”可按用途查看最近使用的文件夹。“曲目与乐谱”、曲库目录、MusicXML、PDF/图片、曲目包、备份、重新定位和各类导出分别记录，互不改变。每类保留最近 20 个位置，实际选择文件后更新，取消不更新，重启保留。

“用于下次选择”将已记录且可用的文件夹设为下一次文件选择的打开位置。失效文件夹显示“当前不可用”，原选择窗口会回到仍存在的上级目录。重新连接后点“刷新位置”核对状态。“移除记录”和“清除此类记录”只清理位置记忆，文件、曲库目录登记、曲目资料保留。

## 导入缓存变化后的重新导入

重复导入同样 MIDI 或 MusicXML 时会核对已存演奏内容和附加资料。若文件被替换或个人资料损坏，保留原件，另建恢复演奏副本，并显示两个位置；可携带同一曲目身份的有效指法与个人资料。再次导入优先复用已恢复副本。损坏或身份不符的资料不自动套用到恢复演奏。
