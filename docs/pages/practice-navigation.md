# 小节导航与完整演奏

## 选择与定位

练习面板底部的小节条显示音乐小节、拍号、不完整小节和拍分组，不按秒数等距分段。拖动选择小节范围，也可 Shift 点击或用 Shift＋方向键扩展；“循环选段”将范围用于练习。放大/缩小改变同屏小节数量，分页浏览与跟随可以分别使用。

“小节”“拍”输入支持定位到实际音乐位置；上一拍/下一拍使用当前拍号，6/8、9/8、12/8 按大拍移动。弱起与变拍截断小节只能定位到实际存在的拍位；循环开启时定位保持在当前范围内。书面小节与反复展开位置的完整对应仍在后续开发。

## 完整演奏与背谱

- **完整演奏**：从曲首演奏一遍，错音和漏音不会阻止播放，结束后自动保存并显示结果。
- **背谱**：采用同样的单遍评分，但隐藏目标音符、乐谱、指法和待弹提示。键盘可以显示自己实际按下的琴键。

可以在开始前选择音轨/手别、速度、预备拍和节拍器。开始后速度、声部与导航条件被保护；暂停后可以继续，改变这些条件需要先重新开始。完整演奏和背谱不使用分段循环或自动提速。

完成窗口可以“再演奏一遍”，也可重练薄弱小节；薄弱段重练切换到连续模式并设置选段。历史将完整演奏、背谱、连续与等音分别比较，不混用等待式练习和节奏演奏成绩。

## 小节边界更新

曲末正好处于小节边界时，不再创建额外空白小节。结束游标停留在最后一个实际小节。此前保存的段落若音乐网格签名变化，需要重新确认起止并保存；旧成绩继续保留。

生成技术练习的右手与左手使用固定轨号，单手练习中未选的手只占空轨位，不显示为空声部。切换手范围时，新启用的手进入自己弹；同一范围重开继续恢复原设置。速度和重复数仍共用同一音乐任务进度，附加资料的缓存以稳定演奏核对，不当作当前实际速度/重复数的播放内容。较早版本单左手的自定义逐音资料轨号仍需迁移审阅。
