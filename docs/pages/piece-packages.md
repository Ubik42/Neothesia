# 曲目包与教学内容迁移

在主菜单打开“曲目包”，导出当前曲目为 `.neopiece`。文件采用 ZIP 容器，可备份到其他目录或在另一台安装了 Neothesia 的电脑导入。

## 包含的内容

- 当前 MIDI 原始内容；生成练习使用当前速度、手别与遍数的实际演奏变体。
- 全部已登记谱面版本与当前关联，保留每份名称。
- 曲名、作曲家、演奏者、作品集、难度、标签和教师备注。
- 指法、逐音左右手、音轨声部、拍号/弱起修正，以及本曲有效的每手跨度。
- 嵌套分组路径、评级、练习设置、当前循环，以及有名称/备注的小节段。
- PDF、图片谱面全部版本及文件副本，页序、当前版本、阅读页码/缩放/旋转。
- 速度阶梯的练习范围、手别/声部条件和提速规则；不带已通过进度。
- 已知的来源和许可信息。

个人演奏成绩、录音、设备路由和延迟校准不属于单曲内容包；完整记录备份仍在开发。

## 导入

选择或拖入一个曲目包，软件先展示曲名、谱面、标注数量、段落、分组评级和来源。导入前选择冲突处理方式：

- **合并，保留本地冲突项**：补充缺少的元数据、标签、指法、分手、谱面和段落；已有标注优先。评级取较高值，补充分组。相同名称/范围/备注的段落不重复加入；同内容谱页不重复登记，补充缺少的阶梯规则，保留本地阅读位置。
- **保留本地标注与练习设置**：已有标注、段落、分组和评级保持，补充谱面版本与谱页，保留本地阅读位置和阶梯。新曲目正常恢复全部内容。
- **使用包内标注与练习设置**：使用包内元数据、指法、分手、网格、分组评级、速度和段落；已有成绩和谱面文件保留；谱页目录、阅读设置和阶梯采用包内内容，阶梯进度重新开始。

文件写入本机应用数据的管理目录，原 MIDI 和谱面文件不改写。导入后可直接练习。已有网格与包内段落不一致时保留段落的来源网格，打开前需要核对和重新保存范围，避免套用错误小节。

桌面与浏览器上限 256 MB；单谱页文件上限 48 MB，登记谱页总量上限 240 MB，包展开总量上限 512 MB。浏览器直接传文件，桌面选择窗口直接读取文件；预览后确认导入使用已校验的凭据。包含丢失或已改变的谱面版本时，导出会指出具体版本，应先修复关联或移除登记。

## 格式与持久化

版本 2 使用 `manifest.json`、`performance.mid` 、`scores/` 与 `papers/` 文件；仍支持读取旧版 v1（没有附件与阶梯字段）。清单分别声明 MIDI 身份、每个资源的名称/大小/BLAKE3 哈希、标注和教学设置。导入先校验清单、所有文件、音符身份/范围、练习范围与乐谱，再写入管理目录。非法相对路径、重复条目、缺少或未声明文件、损坏内容及超出展开限制的包被拒绝。

生成练习导入为固定 MIDI 曲目；技术练习生成器的参数方案继续在“技术练习”中管理。导出和导入先暂停参考演奏；预览在音乐时钟之外处理。

持音换指使用第 6 版曲目包，含原音符身份、换指 tick、原指/接替指、手和推荐速度。旧包没有此字段。合并时保留已有整套换指计划，没有本地计划时才带入；导入后按当前起音指法、分手和速度重查，冲突计划保留供审阅并停止练习提示。


包含手写笔迹、区域高亮或页内小节位置的新曲目包使用 v9，保留完整笔画、粗细、说明和几何位置。旧版软件会拒绝此包，请用新版导入。新版仍读取此前 v1～v8 曲目包；声明旧格式但含手写笔迹的包会拒绝，避免按不完整资料采用。
