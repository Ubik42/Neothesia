# 练习资料备份

在“练习计划”或“练习记录”窗口选择“练习资料备份”。导出 .neopractice 文件，可分别选择计划与日期进度、成绩记录、命名片段/速度阶梯/技术练习方案。成绩可导出全部保留记录或近 30/90/365 天，每曲沿用最多 200 条的保留规则。

周期星期、起止日期和启用/暂停状态随模板携带；复制出来的新模板默认不启用周期。

导入先选文件，查看模板名称、周期与要求、日期数量、成绩数量、各类方案及计划曲目的定位状态。相同编号但内容不同的计划、日期安排和方案分别显示冲突数量，可选择保留本地或采用备份。保留本地仍会补充不存在的项目。完全相同的成绩跳过；同编号但内容不同的成绩分别保留，日期进度引用同步迁移。合并后超过每曲 200 条的成绩保留最新记录，并报告移除数量。

导入前需停止演奏、录音并结束当前计划/阶梯。导入的计划和方案使用本机延迟校准；历史成绩保留当时的实际条件。设备、音源、输入输出和当前演奏状态不从备份覆盖。导入后不会自动开始演奏。曲目文件按内容身份查找；生成练习可以重新生成，其他曲目仍需有可用原文件或曲目包。

该文件不携带 MIDI、MusicXML、PDF、图片或逐音指法/分手。携带这些资料请使用 .neopiece 曲目包；换电脑时可以先导入曲目包，再导入练习资料。

导入验证格式、版本、完整内容哈希、项目数量和练习条件，拒绝损坏或超限文件。文件最大 256 MB，展开内容最大 512 MB。导入前在数据目录 practice-restore-points 保存本机计划设置和历史文件副本；两份文件以恢复日志共同更新，中断后下次启动恢复到一致状态。副本保留，目前尚无界面回退入口。

成绩的练习备注、教师评语和下次重点随备份携带，预览显示评语冲突数量。相同成绩只合并文字，不增加成绩条数；保留本地或采用备份按所选策略处理。旧备份没有评语时保留已有文字。


## 曲目学习资料（Cycle 144）

“计划、日课与曲目学习”包含人工阶段、目标日期、每周计划时长、目标速度、文字要求及阶段记录。存在此资料时使用 v3，兼容读取 v1/v2；导入前查看数量和冲突，再按保留本机或使用备份处理。内容身份关联到以后识别的曲目，不携带文件路径。导入中断时，本机曲库资料与偏好/成绩一并恢复；旧恢复日志不会误处理曲库文件。

## 资料模板

勾选“片段、阶梯、技术练习、音轨与资料模板”后，备份携带常用资料模板。模板只包含字段操作和内容，不携带文件路径，也不直接修改曲目资料。只含模板的备份也可以导入。

导入预览可展开查看每套模板的字段、操作与内容；同名模板不同会列入冲突。“保留本地”继续使用本地同名模板，“使用备份版本”采用备份同名规则，其他本地模板继续保留。模板同样纳入导入恢复点，失败时回到原状态；本地模板文件损坏时拒绝覆盖它。

包含资料模板的备份格式版本为 v4，新版可读取旧 v1-v3。较旧软件不支持 v4，请在新版中恢复。曲目资料变更历史目前仍不在练习备份内。
