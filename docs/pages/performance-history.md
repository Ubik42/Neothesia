# 演奏历史回放与对照

新版保存的练习结果会同时保留实际起音、离键、力度和踏板，以及当轮计分参考音符和踏板。旧记录只有成绩摘要时，不生成假的按键数据。

打开“练习历史”，选择一条记录，展开“演奏回放与起音对照”并读取演奏。上排绿色为参考音，下排蓝色为实际按键；可以选择演奏小节，查看起音、力度和持音时值。新归档的逐音结果直接保存当轮计分器的准时、偏早、偏晚、漏音及错音，并关联具体参考音与实际按键；差值包含当轮输入校准，原成绩保持。旧归档仅按同音前后 0.5 秒就近对照，显示“近似对照”；“附近未找到”不能代替原计分判定。

选择“实际演奏”或“当轮参考音”，设置 25%–100% 速度后回放。声音使用当前输出音源；不会移动当前练习位置或写入新成绩。停止、按琴键接管、折叠或关闭历史、页面隐藏会结束回放。暂停时按下的键在归档中结束，暂停间隔不作为演奏用时。当前小节筛选仅用于对照查看，回放仍播放本轮完整保留事件。

每轮容量达到上限后提示部分数据。练习资料备份勾选“个人成绩与演奏回放”时会携带对应成绩的归档，日期范围同步作用于成绩与回放。导入预览显示回放数量、大小、重复和冲突；相同成绩的回放不同可保留本地或采用备份，同编号而成绩不同则各自保留。旧备份只恢复已有成绩，不补造回放。导入失败会共同恢复成绩和回放，无法读取的本地回放须选择使用备份版本恢复。逐音起音判定随 v7 及以上备份携带，小节边界随 v8 携带，逐音数量和原成绩相互核对；旧 v1–v7 备份仍可读取。逐音力度/踏板专项判定继续开发。

从对照进入重练：选择演奏小节并按“重练所选小节”，或在某个参考音行按“重练这里”。前后可各带 0、1、2、4、8 小节，超出曲首/曲尾时截到有效范围。恢复原声部、速度、预备拍、节拍器、输入校准与轮数；完整演奏/背谱改为连续模式，自适应速度关闭。选段准备好后由用户开始练习，原成绩不改动。反复演奏按展开后的位置选择，原小节或逐音分手已变更会提示重新确认。正在演奏、录音、计划或阶梯时应先结束；历史备注有草稿时先保存或放弃再切换。选段还可在练习区保存为常用片段。

逐音判定查看：按“全部判定”“偏早、偏晚与漏音”或单独等级筛选参考音。漏音参考为红色，偏早/偏晚为橙色，尚未计分为灰色；尚未计分不当作漏音。等音等待超过半秒的匹配仍按实际结果显示。错音另列实际音高、起音、计分时钟、力度和当时参考小节，这个小节是上下文，不代表错音匹配了某个参考音。参考音行仍可进入重练。容量截断时仅显示已保留证据；新版本不重新推算旧归档的计分结果。

在乐谱中重练：参考音行的“在乐谱中重练”会恢复条件、准备所选上下文范围，切到当前关联的 MusicXML 谱面，并标出那次演奏对应的书面音。反复后的第二次同音仍按所选演奏位置准备范围；上方显示历史参考小节及当轮判定。谱面映射必须可靠且唯一，否则提示先校对；没有关联谱面时可直接在练习区重练。标记是历史参考，不是新一轮实时评分，可清除；重新开始练习会恢复跟随演奏。当前关联谱面更新后须重新从历史定位。本功能不恢复历史当时的谱面副本，也不对 PDF/图片进行逐音定位。


整轮谱面批阅：从历史演奏按“整轮谱面批阅”，恢复当轮条件并打开当前关联 MusicXML。准时为绿边框，偏早/偏晚为橙色、漏音为红色、未计分为灰色；旧记录仅显示蓝色近似参考。查看次数按每个书面音各自的展开演奏出现次数计算，可以分别看反复前后的判定。没有该次演奏或没有保存证据的音不涂为漏音，歧义谱音不着色，错音独立计数。截断记录只统计保留资料。

用上一/下一问题音浏览偏早、偏晚与漏音，软件会切换该音的次数和谱页。展开参考音列表后可以筛选判定、查看起音和力度，并选择前后小节上下文进入“重练这段”；原成绩保持。结束批阅会清除边框，更新关联谱面后需重新从历史进入。当前没有历史原谱副本恢复或 PDF/图片逐音批阅。


随谱回放：批阅区选择实际演奏或当轮参考音、速度，再按“随谱回放”。按当轮保存的参考起音时钟更新演奏次数、谱页和可见位置；蓝色虚线表示回放经过的参考起音位置，并不代表实际错音匹配。原判定边框保留，主练习位置和成绩保持。回放中不能手动改次数、跳问题或重练，停止后恢复。按琴键接管、开始主练习、隐藏页面、关闭批阅或切换视图会停止；声音使用当前音源。谱面映射不可靠时须先校对；历史音色/伴奏完整还原继续开发。


回放控制：历史对照和谱面批阅均支持暂停/继续、拖动进度条、输入秒数后“定位回放”，以及回放中调整速度。播放中定位后继续播放，暂停中定位保持暂停；结束后可定位到较早位置再继续。位置是当轮保留的演奏时钟，等待时间包含在内。暂停时声音关闭，续播或跳转恢复所在位置的按键、力度、各通道踏板与踏板延续音；音源重新起音，音色包络和尾音不保证连续播放的采样级一致。操作不改主练习位置和原成绩，退出或按琴键接管停止。完整历史音色/伴奏还原继续开发。


小节定位与循环回放：展开同名区域，选择演奏小节及该小节的练习出现次数，按“跳到参考起音”。普通反复按展开演奏小节区分；反复练习同一个演奏小节时选择次数。新记录定位已保存的小节起点，休止小节也可选；旧记录只定位首个保留参考起音，无证据时提示不可选择。新记录“采用小节范围”使用当轮已保存的起终点；旧记录“采用小节参考范围”选到下一小节首个参考起音，末尾到本次回放结束，可再改起终点。

起终点可以直接输入，或用当前位置“设为起点/终点”，至少相距 0.1 秒。启用“循环回放选段”后独立反复并显示完成次数；暂停保留范围，继续后仍循环。“关闭回放循环”保持位置并恢复后续全轮播放。在循环外定位应先关闭循环。终点音不播放进下一遍，跨界按键和踏板在起点重新建立；原主练习循环、成绩和历史不改变。回放范围本次临时使用，循环段收藏继续开发。


新演奏的小节边界：新版 v3 演奏归档从真实演奏推进保存小节起终点和原曲范围，休止、等音等待、实际速度均以当轮运行时钟为准；曲尾成绩等待不算入小节。暂停间隔不加入演奏时钟。选段仅经过半个小节时会提示“已演奏部分”，范围不补成整小节。最多保留 100000 段，达到上限提示不完整。没有参考持音的休止处不显示假的回放音符，当前小节仍可查看。

个人成绩与演奏回放备份采用 v8 携带这些边界，导入和恢复保持共同处理。旧演奏归档 v1/v2、旧备份 v1–v7 保持可用；没有保存边界的旧记录继续显示参考起音定位，不凭现在的曲目重算过去等待和休止时间。


## 收藏回放片段

在小节定位与循环回放中采用小节范围，或设置起终点，再展开“收藏的回放片段”，输入名称与备注保存。收藏属于当前演奏记录，可查找、修改、删除。采用收藏范围后可循环回放；定位片段起点会关闭已有回放循环，并保持当前暂停/播放状态。开始回放前可查看或采用收藏，新增/修改需要读取对应演奏归档并通过时长校验。

每条记录最多 100 个收藏，片段至少 0.1 秒。修改不改变原成绩、声音归档和历史身份。旧入口的陈旧保存被拒绝；重新读取更新列表并保留名称/备注输入。未保存文本暂留当前窗口，起终点以上方范围为准。声音归档不可用时仍可查看或删除收藏，不能创建/修改不具备时长证据的范围。

v9 练习备份携带收藏；相同演奏按收藏编号合并并预览冲突，可保留本地或采用备份，双方新增项保留。旧 v1–v8 备份无收藏时不清空本地片段。历史同编号冲突时收藏随对应演奏归属重映射，修改收藏不会制造重复演奏记录。


## 多个问题段落练习

从整轮谱面批阅打开“编排问题段落”，勾选偏早、偏晚、漏音，调整顺序与前后小节。每次最多 60 个问题音，相同起终小节合成一项，重叠但不同范围分别练习。预览按所选问题的第一次出现保留顺序；同范围的名称/要求在重新预览后继续保留。旧演奏没有逐音判定时不能自动当成问题音。

原声部、逐音分手与小节网格需仍一致，参考音应有唯一原曲对应。设置等音或连续模式、速度、次数、正确率/准时率及轮数上限，预览并逐项编辑名称和要求后保存。可新建计划，或追加已有常用计划/指定日期安排。按日期追加保留既有进度，新建时可同时产生独立日期快照。保存后“打开已保存计划”定位到对应计划，打开项目后沿用正常开始练习、真实达标及打开下一项流程。

改变原演奏证据、谱面版本、网格/声部、本机校准或目标计划后，旧预览不能保存，需要重新预览。容量与写入失败整批回滚。新建请求重试返回同一计划，完全相同项目跳过，文字要求不同则保留。项目和日期进度沿用原有练习备份。关闭编排窗口保留当前输入，未保存结束批阅需要确认；离开批阅不作后台保存。原历史声音、判定和成绩保持。


跨记录、跨曲目复习：在历史详情按“加入复习编排”，可收集最多 20 条记录。在“复习编排”里跨曲选择偏早、偏晚和漏音，共最多 60 个问题，按小节上下文生成项目。相同记录的相同范围合并，其他范围保留，可交错调整曲目顺序。预览后逐项改名和写要求，保存为常用计划或指定日期日课；每项恢复自己的原曲、声部和分手，实际达标后按下一项切换。

记录清单、所选问题、条件和人工文字暂存于本机，关闭历史后可回来继续；移出的记录仍有选中问题时需移除缺失项或重新加入原记录。每条记录先读取 200 个问题，可分批继续读取。预览不切换当前曲目，不改原成绩或演奏位置；保存前重新核对原文件、演奏归档、网格、手别和目标计划，变化后须重新预览。缺失来源或任一项目无效时整批不保存。PDF/图片逐音历史映射与拍内范围继续开发。


项目拍内裁剪：单曲或跨记录编排生成预览后，各项勾选“裁剪到拍内范围”，设置原演奏小节与拍位，再按“核对拍内范围”。每项沿用自己原曲的拍号与速度变化。裁剪必须包含全部所选问题起音，终点起音排除；不能超出此前选择的上下文小节。需要扩大范围时先调整前后小节再生成。修改或恢复草稿后须再次核对；保存前重新核对来源，日课、跨曲切换和备份均保留精确范围。原谱书面端点与一般不连续片段仍继续开发。
