Neothesia · 钢琴练习室

双击 Neothesia.exe 或 Open.cmd。请保留同目录的 default.sf2。
前端、乐谱排版和 Rust 音乐引擎已打包；不需要开发服务器、Node.js 或 Rust。
本机需安装 Microsoft Edge WebView2。

1. “打开文件”选择 MIDI、MusicXML 或 MXL，添加曲库文件夹，或用“技术练习”生成音阶、琶音与和弦练习。
2. MIDI 键盘会自动连接；“设备设置”可选择输入、内置钢琴、MIDI 输出或 VST3 乐器。
3. “等音”弹对后继续；“连续”按参考 MIDI 时序评分；“聆听”自动演奏。
4. 音轨可设为自己弹、伴奏、静音，并指定左右手；单轨文件不自动按中央 C 分手。
5. 循环起止使用小节，可设遍数、预备拍、节拍器和自动调整速度。
6. 可配对 MusicXML/MXL 乐谱并跟随演奏，也可在键盘提示中编辑手动指法。
7. 每轮自动保存；逐小节反馈可以直接重练。历史、收藏、队列与复习提示保存在本机。
8. “录制演奏”记录真实 MIDI 输入，停止后可回放和导出 MIDI。
9. 空格开始/暂停；默认 A S D F G H J K 试弹；“显示设置”可改变起始音区、按键布局并逐音自定义。“停止发声”用于紧急停止。
10. “显示设置”可切换音名/唱名/大调级数、指法提示、键上文字、字号与左右手蓝橙配色，键盘范围/预览小节和面板开关自动保存。级数只改变提示，右下数字表示音区，不改变演奏音高。

11. 曲库多选后“批量修改资料”：设置保留/替换/清空，标签和备注可追加；先读取逐首变化预览，再保存勾选项。资料变化或文件换内容时拒绝旧预览覆盖，须重新读取并检查。常用规则可保存资料模板，重启保留，也可随练习资料备份的预设范围迁移。
12. 曲库左侧“最近文件位置”按用途记住文件夹，可设定下次打开位置或清理记录；失效目录回到可用上级。清理记录不删除文件。

13. 曲库详情“资料变更历史”查看单首/批量资料保存记录，按字段预览恢复到修改前。同字段后来改过时明确选择，恢复前再核对，恢复本身也留记录，可反向恢复。历史按当前文件位置区分，保留最近 200 次写入，尚不随练习备份携带。

14. 乐谱下“演奏顺序”按原谱小节选择第几次演奏，可定位或“循环这一段”；返回和尾声处仍跟随原谱。带 * 的段只演奏该小节部分，说明显示实际拍位。MusicXML 需包含明确 sound 跳转目标/指令；只有 D.C./D.S. 文字、缺失目标或复杂未支持结构会提示校对。谱面指法编辑中可分别修改同一谱音的多次演奏位置。

15. 乐谱“演奏顺序”→“选段练习”分别选择起止原谱小节及演奏次数，先阅读实际经过的小节。跨返回/跳转时确认采用该路径，再循环或命名保存。“练习段落”可打开原谱段、只修改名称/备注或重新审阅范围；源谱变化时须重新核对。原谱段可加入练习计划，并随 v5 曲目包/练习资料备份迁移。

默认曲库：D:\Music\MIDI\PracticeLibrary。也可通过 NEOTHESIA_LIBRARY_ROOT 指定。
用户设置、录音和练习记录位于 com.ubik.neothesia 应用数据目录。
各曲的音轨、声部、模式、速度、循环与预备拍会独立恢复。
缺失的本地曲目可重新选择同一内容的原 MIDI；不相同的文件应作为新曲目导入。

GiantMIDI 为自动转录，拍号、音符和手的归属可能需要校对。
缺少拍号的 MIDI 按 4/4 暂显并标记；软件不把默认拍号当成校对结果。
乐谱配对有歧义时跳过对应高亮；不安全的反复导航不用于跟随。
力度、踏板、时值与输入延迟估计只在有足够参考和样本时显示。
Pianoteq VST3 已接入；长时间手弹、硬件断接与所有插件编辑器行为仍需持续验证。

新增操作：
“曲库管理”可以多选曲目、按分组整理、设定评级、编辑难度/标签和查看谱面状态。
“指法建议”按明确手别与手的跨度生成音符、和弦或小节选段建议，逐条修改后接受保存；可撤销。
“练习段落”保存有名称和备注的小节段，同时记住当前声部、模式、速度、预备拍与遍数。
“技术练习”可以保存常用配置，下次选择同一方案再生成。

Cycle 112 新增：
“逐音分手”按音符指定左右手，也可生成建议后逐条确认；保存会用于分手练习、伴奏和指法推荐。
“指法建议”可分别选择左右手，每只手可保存跨曲默认跨度。
“修正小节网格”设置整曲拍号及首小节弱起，或恢复原始网格。变拍号编辑仍待开发。
“谱面管理”保存多个 MusicXML/MXL 版本，支持切换、改名、解除关联与移除登记，原文件保留。
修正网格后旧练习段需要重新核对范围；历史趋势按实际目标与网格分别计算。

Cycle 113 新增：
“导入曲目”可多选或拖入 MIDI、MusicXML、MXL，复制到本地管理目录，逐项显示结果；可暂停和继续。
MusicXML/MXL 可直接生成演奏并练习，保留原谱、常规反复/一二房、拍号、弱起、连音、踏板和谱面指法。
钢琴双谱表生成左右手音轨；其他谱表需确认声部分配。D.C./D.S./Coda、移调谱及复杂跳转会明确提示不支持；装饰音和自由时值有提示。
“曲库管理”中“后台索引全库”可以暂停、继续、取消；关闭窗口后仍运行，重启后从已保存进度恢复。

Cycle 114 新增：
“曲目包”可导出当前曲目的 MIDI、所有谱面版本、指法/分手、元数据、分组评级和练习段落，保存为 .neopiece。
选择或拖入曲目包，先查看内容，再选择保留本地、合并（本地冲突项优先）或使用包内内容。
导入文件保存在本机管理目录；原文件保留，个人成绩与设备设置不从曲目包覆盖。
生成练习打包当前速度与遍数对应的实际 MIDI，导入后作为普通本地曲目使用。

Cycle 115 新增：
小节导航条支持拖动选段、Shift 点击/方向键扩展，放大/缩小、分页及跟随；“循环选段”应用范围。
输入小节和拍位后定位；上一拍/下一拍按实际拍号移动，6/8 等复拍子按大拍，弱起只包含实际拍数。
“完整演奏”与“背谱”从曲首演奏一遍，结束后评分；背谱隐藏谱面、目标音符和指法提示。
完成后可再演奏一遍，或重练薄弱小节；后者自动转为连续模式。模式分别保存和比较。
修复了曲终多余的小节；网格发生变化的旧命名段落需要重新确认并保存。

Cycle 116 新增：
“练习历史”可按曲名/路径、模式、左右手、选段与日期筛选，并翻页查看每首曲目保留的最近 200 条记录。
选择记录查看当时成绩、已评目标音符/部分结果、声部设置、逐小节错漏和同条件的上次/最佳/走势。
“恢复这次练习”恢复那次实际参数；生成练习恢复那次实际变体。重练按钮恢复条件后切换为连续模式练该小节，不自动开始。
旧记录没有完整条件时只能打开曲目。原文件内容改变会拒绝；网格/分手改变时保留现有标注并提示重新确认范围。
部分保存不代表整曲完成，新记录中的部分结果不会作为掌握证据延后复习。

Cycle 117 新增：
右侧“速度阶梯方案”设置小节范围、起始/目标速度、步长、连续达标次数、正确率、准时率及未达标处理。
保存方案后“从起始速度应用”，再按主界面“开始练习”。整轮连续达标才提速，目标级也需达标；未达标可重复或回退。
阶梯期间不能改速度、声部、范围、拍号等条件；“结束阶梯”保存当前级别，“继续保存进度”从该级继续。
每方案独立保存进度，关闭软件后不会自动演奏；仅改名保留进度，更改条件会清除该方案旧进度。
历史显示方案及级别；低于阶梯目标的成绩不会计作该目标已掌握。等音阶梯不评价节奏，节奏门槛请用连续模式。

Cycle 118 新增：
顶部“练习计划”区分常用模板和当天安排。模板支持多曲目、命名选段和阶梯项目，加入时保存具体条件。
设置达标次数、正确率、准时率和文字要求；可排序、编辑、移除、复制为新模板。首次使用时复制到日期，随后各天独立。
项目行“练习”直接打开；按主界面开始练习。实际整轮达标才计完成，达标后可“打开下一项”，不会自动切曲演奏。
“结束本项”保留进度；保存重启后从当天安排继续。跳过与达标分开，跳过原因有独立输入。
修改当天本项目标/条件重置进度但保留历史，只改文字说明不清除次数。模板移除保留已有日期安排。
历史记录会保存当时计划、日期、项目和文字要求。文件/网格/分手改变时需重新确认条件。

Cycle 119：曲库管理支持字段查找、负词排除、评级/时长/成绩筛选、真实最近成绩排序、查询保存与跨页键盘连续选择。

Cycle 120：曲库管理新增自动更新开关、立即检查、断开目录提示与恢复补索引；同内容改名可恢复个人附加信息，收藏/历史/日课按内容查找新路径。不会自动切换当前练习。

文件改名、移动或重复副本：打开“曲库管理 → 文件位置”，核对和关联可用位置；可设置常用位置、合并/恢复显示或忽略旧位置，原文件与练习记录保留。

PDF / 图片谱面：在“谱面管理”添加、改名或调整图片页顺序，主练习区“谱页”可翻页、缩放、旋转，并保存阅读状态。扫描谱可手动翻页，建立小节对应后也可自动翻页；曲目包携带附件及对应。

乐谱指法：在 MusicXML/MXL 乐谱中启用“谱面指法”后点选符头，可改手指、逐音分手、查看推荐原因、采用建议和撤销。反复谱音按对应小节选择位置，全部应用作为一笔修改。原谱印刷标记保留。

曲目包可以携带 PDF/图片谱页、阅读位置及速度阶梯规则。曲目包上限 256 MB；导入先预览，可保留本地资料、合并或使用包内设置。个人成绩、阶梯进度及设备校准留在本机。
乐谱支持适合宽度或 75%–200% 缩放；重点指法可减少连续顺指的中间标注。

曲库管理选中已索引曲目后，右侧列出全部谱面版本，可改名、管理关联、预览 PDF/图片或打开指定版本。相同名称/内容重新导入乐谱会复用登记；旧重复登记可合并，谱面文件仍保留。

Cycle 126：指法建议支持至多三个不同路径比较、固定手指后重新计算、逐位置键盘手位/持音预览，保存一笔可撤销。修改手指后需“按修改重新推荐”；旧方案不会写入已改变的音符或分手。谱面逐音编辑使用相同搜索。

Cycle 127：曲库资料区直接添加多份演奏乐谱或 PDF/图片，同批图片合并为多页谱，可追加、重排及确认移除页登记。缺失/改变附件按原文件内容修复，保留版本编号和阅读位置；新内容请添加新版本。批次显示逐项结果，可处理完当前文件后停止。

Cycle 128：计划和记录窗口顶部“练习资料备份”导出 .neopractice，可选计划/日期进度、成绩及练习方案，支持成绩日期范围。导入预览冲突，保留本地或采用备份；相同成绩去重，同编号不同内容分别保留。先停止演奏、录音、计划和阶梯。设备/延迟使用本机设置，曲目文件及逐音注记另用 .neopiece 携带。自动保存导入前本机恢复副本，当前没有界面回退入口。

Cycle 129：常用计划展开“周期安排”，选择星期、开始/结束日期并保存。打开符合规则的日期时自动建立缺少的独立日课，不自动演奏。既有安排/成绩不随模板覆盖；暂停/取消只影响未建立日期，复制模板默认手动安排。周期规则随练习资料备份携带。

Cycle 130：练习历史选择成绩，可编辑练习备注、教师评语、下次重点并保存；未保存时先保存或放弃后切换/关闭。查找支持评语文字。评语不改变评分，随所属成绩和练习资料备份保存；相同成绩的评语合并不增加条数，其他操作改过评语时拒绝覆盖旧页面。

Cycle 131：练习计划展开“从历史薄弱小节安排复习”，生成证据、查看原条件并勾选加入模板/当天安排或新计划。至少两次完整小节及八次音符判断、正确率低于 90% 才建议。建议慢速连续两轮达标，不自动演奏；相同项目跳过。当前只针对音符准确性，打开时仍核对实际文件和条件。

Cycle 132：复习建议增加节奏专项。至少两次完整连续演奏小节及十二个有效节奏样本、准时率低于 80% 才建议，等音不评价节奏。预览显示准时率/样本/偏移/波动；加入后开启节拍器，连续两轮正确率至少 90%、准时率至少 85% 才达标。正确但不准时显示“准时率未达标”，不计完成。

音轨声音（Cycle 133）
展开右侧各音轨的“声音设置”，调整伴奏音量、声像或内置钢琴音色，再“应用并保存”。仅作用于伴奏与试听，不改写原击键力度，也不调整 MIDI 键盘输入。应用会暂停并重置本轮；“恢复原曲”删除该轨自选声音。每曲自动保存，曲目包与练习资料备份也可携带。
预设名称来自附带的真实钢琴音源。独立混音最多 14 个旋律通道和 1 个打击乐通道；超限曲目会提示，多个独立打击乐声部暂不支持。外部 MIDI 音源/VST 插件的音量与声像依赖设备支持，自选钢琴音色只用于内置钢琴。

音轨名称与颜色（Cycle 134）
展开右侧音轨“名称与颜色”可重命名或选择颜色，也可恢复原名称与按手别配色。原曲名称保留可查，未提供名称时使用编号。色标、键盘提示音符和图例一致；待弹音继续高亮。改名换色不会暂停或重置当前练习，也不改原 MIDI 文件。名称和颜色按曲目保存，并随曲目包、练习资料备份携带；颜色目前作用于键盘提示，书面谱面保持原样。

力度与踏板练习目标（Cycle 135）
在练习计划项目中可勾选力度平均差上限、力度起伏一致率或踏板时机偏移。按参考 MIDI 比较，键盘力度曲线会影响绝对差值，可只选择变化方向。全部已选要求和正确率/准时率都满足才计达标；缺少样本不会自动通过。保存所选范围参考数据不足时会提示。
平均差至少 4 个匹配音符，力度起伏至少 6 段明显参考变化；踏板至少 4 次转换且全部对应，波动不超过 120 ms。等音不评价踏板时机；速度阶梯目前沿用独立晋级规则。主练习区显示要求与上一轮失败原因，历史保留当时目标及该轮专项结果。

历史专项复习：在“练习计划”展开“从历史练习安排复习”，生成后预览勾选，加入常用计划或所选日期。音符/节奏按小节复习，力度起伏/踏板时机沿用原整曲或选段。至少两轮完整且音符正确率达标才评价表达；无踏板输入不生成踏板建议。专项要求与实际失败原因在练习区显示，可在项目里修改。踏板和音符共用设备输入校准。

纸谱自动翻页：进入“谱页”，展开“小节与谱页对应”，翻到需要的谱页并填写实际演奏小节，保存后开启“自动翻页”。反复回到旧页可为后面的演奏小节再次关联旧页。手动翻页会暂停跟随，点击“继续跟随”恢复；同页内可自由滚动。修正拍号/弱起后需核对并“按当前小节重新确认”，再开启跟随。曲目包携带对应关系；有对应的 v3 包需要本版或更新版本打开。

谱页批注：在“谱页”点击“添加批注”，再点击页内位置，输入教师提示、指法备注或练习重点并保存。点编号可修改、重新定位或删除；本页列表查看完整文字。编辑期间自动翻页暂停，先保存或取消再翻页；未保存内容保留为本机草稿。批注随缩放/旋转/图片重排保持原位置，删页会删除该页批注。曲目包携带批注；含批注的 v4 包需要本版或更新版本打开，未改写原 PDF/图片。


个人标记谱：打开“乐谱”，点击“导出标记谱”，选择个人指法/逐音分手并核对数量。反复同一谱音设置不同，默认保留原谱中有分歧的标记；可选择采用首次演奏，预览可查看每次设置。保存 MusicXML 副本带到其他制谱软件，原谱不自动改写。分手以左手/右手文字标注，不移动原谱表声部；未接受推荐、纸谱批注不写入。修改后需刷新预览。


谱页批注图片：在“谱页”点击“导出本页批注”，保存完整当前页的 PNG。包含当前旋转后的编号、页后完整教师文字说明；隐藏编号仍导出已保存内容，阅读缩小不降低 PDF 导出清晰度。先保存或取消草稿。导出期间暂停跟随；只导出当前单页。批注过多/图片过大时明确提示，可改用曲目包完整分享。


原谱更新：桌面直接打开 MusicXML/MXL，或在曲库添加演奏乐谱时会关联原文件。旧保存版本可以“关联原谱文件”选择与其内容相同的原件。进入曲库“原谱文件”或谱面管理“检查原谱更新”，查看更新/缺失状态，先预览新内容，再添加为新谱面版本或建立并打开新演奏曲目。仅加谱面保留原演奏，使用时另选新版本；演奏内容不同不会把旧指法/成绩/片段自动套到新音符。同内容继续原身份。应用前停止演奏、录音、计划与阶梯。
“保留当前版本”确认暂不采用这一份新内容；原件再次修改仍会提示。取消原件关联只停止检查，不删除保存版本和曲目。原件路径仅保存在本机，不随曲目包迁移。

原谱批量处理：曲库管理 → 原谱文件，勾选更新并批量预览。逐项选择跳过、添加谱面、保留版本或生成演奏；失败项显示原因并继续，停止保留完成结果。生成演奏会依次打开，结束停留在最后成功生成的曲目。

整段指法示范：指法建议 → 生成建议并选择方案 → 示范整个建议选段。25% 至原速，实时手位与持音。先停止练习并松开琴键；示范不计成绩、不保存指法。切换方案、按琴键、关闭窗口会停止。

曲目学习：曲库管理 → 选择已索引曲目 → 学习目标，保存阶段、目标日期、每周计划时长、目标速度和要求。可筛选逾期/阶段及排序，也能批量设置阶段而保留原目标；资料随练习备份的计划类别携带。

学习用时：本轮真实运行时间显示在导航条，保存后进入历史。曲库详情和学习目标可查看本周/合计及每周计划进度；统计最近 200 次已保存结果，包含等音等待、排除暂停和预备拍，旧记录未计时，不代表持续实弹或终身累计。

曲库操作：行右键或 Shift+F10 打开菜单；Ctrl+F 搜索，表格 Ctrl+A 全选筛选结果，Ctrl+C 复制所选位置，F2 编辑。支持多选收藏/队列、进度及停止；桌面版可打开原文件位置。信息编辑须保存或取消后再切换/关闭，不移动或删除原文件。

信息审阅：编辑读取当前真实资料，保存核对身份及打开时的原资料；发生并发修改时逐字段选择，合并到草稿后再保存。换曲或资料损坏时拒绝覆盖，草稿可复制；读最新资料不会自动丢弃本地修改。


批量谱面配对：导入曲目 → 批量配对谱面，一批加入 MIDI、MusicXML/MXL、PDF 和图片。先读取候选，预览核对归属；同演奏同名图片纸谱按列表顺序组页。填写批次名称并保存，可从“已保存批次”重开继续。保存中断项先核对实际文件，采用已有结果或恢复待保存；移除批次只清理整理副本。批次保存在当前本机应用资料，可单独导出 .neoscorebatch 迁移，不随曲目包或练习备份携带。


两手交接慢练：指法建议 → 双手一起审阅 → 核对保存结果，查看同键持音重叠及两手音域位置。可筛选并定位两手指法，确认后整理双手难点练习段，保存慢速、小节范围、重复和交接要求，再从练习段落目录打开。实际身体动作仍需人工核对。

Cycle 202：指法建议和双手审阅增加“逐音比较方案”。选择对照方案、小节与差异后局部采用，不替换其他编辑。编辑变化需重新比较；单手按修改重新推荐，双手重新核对保存结果。

Cycle 203：批量配对窗口 → 导出/导入整理批次，携带实际文件、配对和图片分组顺序。导入先预览、核对本机演奏，再另存新批次；来源已完成谱面需核对本机文件，采用后继续组页。此文件携带整理材料，个人指法、批注和练习记录通过曲目包或练习备份迁移。
