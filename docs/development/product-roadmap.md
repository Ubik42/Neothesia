# 钢琴练习软件长期开发路线

更新时间：2026-10-13。此路线是当前长期任务的执行清单，功能完成需要有真实操作入口、数据持久化和可继续编辑的流程。

## 产品范围

主要对象是本地曲目、关联谱面、声部、教学指法、练习段落、练习方案和演奏记录。保留原版 Neothesia 的优势，并逐项对照 Synthesia 的可用功能；不把少量样例、按钮数量或启动检查当成完成度。

已核对 [Synthesia 曲库操作](https://synthesiagame.com/support/guide/choosingSongs)、[内容与元数据指南](https://www.synthesiagame.com/support/guide/contentCreators)、[声部设置](https://www.synthesiagame.com/support/Guide/songSetup) 和 [导入曲目](https://www.synthesiagame.com/support/Guide/addSongs)。它的参考范围包括曲库分组、评级/难度和排序、可搜索元数据、各曲声部配置、伴随文件、MIDI/MusicXML 导入，以及等音、节奏和完整演奏练习。官方指法提示编辑不能当作自动推荐算法的证据；我们的推荐算法来自本地 Fork 的成本模型和动态规划。

原仓库已有路线见 [roadmap.md](roadmap.md)、[backlog.md](backlog.md) 和 [指法算法文档](../pages/fingering-suggestions.md)。原生已实现、Web 已接入、仍需扩展分开记录。

当前批次：Cycle 315（普通练习段写盘失败不污染内存，源码开发中）。已完成项代表下面描述的范围，未完成的扩展继续保持开放。

- [ ] 图片谱面的多页识别路径已写入源码：界面按保存页序生成临时 PDF，桌面端逐页核对内容身份、在识别前后检查原图片，结果仍进入演奏路线预览。多页图片总量与临时 PDF 均限 32 MB。WebP 单页或混合页在识别时优先无损转换为 PNG；单页超过 8 MB 或当前 PDF 图片预算不足时，临时转换为高质量 JPEG。软件保留已导入的 WebP 原件；单页 WebP 原件限 48 MB，转换后的 PDF 限 32 MB。尚需前后端构建、真实 Audiveris 图片识别及桌面点击验证，当前不能作为已可用功能发布（Cycle 241、251–252 开发中）。
